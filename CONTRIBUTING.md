# Contributing to Educational Roadmaps

We love your input! We want to make contributing to this project as easy and transparent as possible.

## How to Contribute
1. Fork the repo and create your branch from `main`.
2. If you've added data to `/data`, ensure it is in standard JSON format.
3. If you've changed APIs or scripts in `/scripts`, update the documentation.
4. Issue that pull request!

## Code of Conduct
By participating in this project, you agree to abide by friendly and professional behavior.
